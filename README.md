# MoveTrack

Mobile step/movement tracker with:
- improved accelerometer peak detection
- profile settings (name, height, weight, goal)
- estimated distance and calories
- active-time tracking
- daily history for up to 30 days
- responsive mobile UI
- PWA manifest and service worker
- install prompt where supported

## GitHub Pages
Upload `index.html`, `manifest.webmanifest`, `sw.js`, and `icon.svg` to the repository root, then enable GitHub Pages from the repository Settings > Pages.

For full offline/PWA behavior, serve the site over HTTPS (GitHub Pages does this automatically).

Note: browser-based step counting is an estimate and cannot match a dedicated phone/fitness sensor in all conditions.
